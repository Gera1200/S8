# REQUEINE — Canvas interactivo, paquetes 2, 3 y 5

## Uso
Abra `index.html` en un navegador moderno. No requiere instalar dependencias ni disponer de conexión a Internet. Se puede publicar como sitio estático en GitHub Pages.

## Paquete 2: Captura y tratamiento
Demostración de captura con folio y etiqueta CAPTURADO, consulta de bandeja, reutilización del flujo de atención y registro manual de entrega externa. El formulario es ilustrativo y no reemplaza el formulario real de AR.

## Paquete 3: Bandeja de Control y campana
Cambio de rol: Revisor 1 (consulta compartida del área), Revisor 2 (finalizados asignados), Administrador (universal, incluidos remitidos) y Operativo (sin Control). La campana muestra **eventos simulados**, no un catálogo de notificaciones aprobado.

## Paquete 5: Envío y recepción de respuestas
Emisión de parciales, total y alcances; finalización manual condicionada al rol, respuesta previa y ausencia de revisión/firma pendiente; primera consulta de AR, simulación de acuses por descarga y alertas. El prototipo no calcula fechas hábiles ni genera PDF oficial.

## Alcance y limitaciones
Los datos se mantienen en memoria mientras la página permanece abierta y se reinician al actualizarla. No existe backend, autenticación real, carga de archivos, firma electrónica, envío de correos, persistencia, cómputo de calendario o servicios externos. El objetivo es validar flujos, no sustituir las RN detalladas.

## Archivos
- `index.html`: interfaz y estilos.
- `app.js`: datos de prueba, navegación y simulaciones.
- `README.md`: guía.
